# Thiết kế giao diện

[Tài liệu](../README.md) · [Frontend](../../apps/frontend/README.md) · [Contributing](../contributing.md)

Các tài liệu thiết kế ghi lại hướng bố cục và lý do chọn thành phần. Giao diện đang chạy, responsive states và accessibility phải được đối chiếu với source và rendered tests.

| Bề mặt | Điểm đọc |
| --- | --- |
| Lịch khám bác sĩ | [Schedule design](stitch-doctor-schedule.md), [doctor appointments](../../apps/frontend/app/doctor/appointments) |
| Thông báo | [Notification design](stitch-notification-panel.md), [NotificationCenter](../../apps/frontend/components/NotificationCenter.tsx) |
| Đăng nhập và Google | [Login design](../login-ui-refresh.md), [GoogleSignInButton](../../apps/frontend/components/GoogleSignInButton.tsx) |
| Theme và responsive | [Shared styles](../../apps/frontend/app/styles.css), [rendered test guide](../frontend-rendered-tests.md) |

Mục được ghi là đề xuất hoặc backlog trong bản thiết kế chưa phải hợp đồng đã triển khai. Bản xuất công cụ, prompt thô và ảnh prototype được giữ local; gallery công khai dùng [media có nguồn gốc](../media-guide.md).
